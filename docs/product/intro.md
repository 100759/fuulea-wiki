# 辅立码课是什么

**辅立码课**（智慧教学云）是一套面向中学教学的智能化教学平台，覆盖「任务布置 → 学生作答 → 批改阅卷 → 学情分析 → 靶向提升」完整教学闭环。平台由**河北习知软件科技有限公司**研发运营，生产站地址为 <https://lyyz.fuulea.com>。

## 产品矩阵

| 端 | 载体 | 主要用户 | 核心能力 |
| --- | --- | --- | --- |
| 教师端 Web | 浏览器登录 | 任课教师、班主任 | 任务发布、批改阅卷、学情诊断、靶向教学、考试系统 |
| 辅立教学小程序 | 微信小程序 | 教师 | 随时随地批改作业、语音讲解、学生管理 |

| 扫卡客户端 | Windows 客户端 | 教师/教务 | 客观题答题卡扫描阅卷 |
| 后台管理 & 录入站 | 浏览器 | 运营人员 | 账号管理、数据录入、内容配置 |

## 六大任务类型

老师日常布置的作业在平台中统称为「**任务**」，分为六种类型：

1. **课程任务**：「码上提分」精品课程、校本课程、名校课程
2. **资料任务**：PPT、英语听力等学习资料（学生只可观看学习，不可作答上传）
3. **答题卡任务**：制作答题卡/试卷，支持客观题+主观题
4. **背诵任务**：语音类背诵作业（只可上传音频）
5. **题库选题任务**：从平台题库筛选题目组卷
6. **选卷任务**：整套发布高考真题、校本试卷

> 另有**学科网选题**：绑定学科网账号后，可直接选取学科网题目组卷发布。

## 核心教学理念

- **数据驱动**：每次任务自动沉淀作答数据，形成年级/班级/个人三级学情画像
- **错题闭环**：错题重练 → 共性错题 → 举一反三 → 靶向教学，层层递进
- **减负增效**：学生互阅、教师批阅、学生自阅三种阅卷方式，减少机械批改时间
