# 老师公开示范课操作教程

> 公开示范课（明星示范课）的核心目的，是以数据化「讲评练」的方式，让辅立码课快速融入教师的课堂教学环节，
> 逐步形成教师自己的教学特色，**以点带面提升讲评课整体质量**。
>
> 本教程配套一节完整的公开示范课实录，页面中的插图均截取自该实录，方便对照学习。

## 一、认识公开示范课

- **适用场景**：以近期考试或作业讲评课为主，建议「至少一文一理」各开一节，覆盖不同学科特点。
- **与常规讲评课的区别**：用真实学情数据驱动，而非传统「满堂灌」式逐题讲解。

### 课堂四大环节总览

| 阶段 | 核心动作 | 辅立码课支撑 |
| --- | --- | --- |
| 课前准备 | 发布练习、批阅、看得分率数据备课 | 任务发布 / 自动批阅 / 学情看板 |
| 课上讲解 | 大屏讲重点共性题、互动讲题 | 大屏讲题 / 精准讲评 / 随机点名 |
| 当堂巩固 | 发布变式题、二次反馈 | 变式题推送 / 实时反馈 |
| 课后闭环 | 个性答疑、板书与微课推送 | 板书发送 / 语音讲题 / 资源沉淀 |

## 二、课前准备：数据备课，锁定讲评重点

<a id="before-class"></a>

课前准备是示范课成败的关键——只有用数据锁定重点，课上才能「讲在刀刃上」。

1. **发布并批阅练习**：教师准备学生需要提交的练习题，在课前发布给学生，完成提交与批阅
   （客观题系统自动批阅，主观题建议学生互阅或由教师批注）。
2. **查看得分率数据**：识别共性薄弱点。例如本课例课前习题：第 1 题得分率 92%（基本掌握）、
   第 2 题 63.2%（部分错）、第 3 题仅 22.8%（大部分错）——课堂重点自然落到第 2、3 题。
3. **确定讲评重点**：依托得分率数据确定讲评重点，做到「有数据支撑」，而不是凭经验猜哪里不会。

![课前诊断：大屏展示课前共性问题](/images/beforeclass-diagnosis.jpg)

<p class="caption">课前诊断：教师在大屏上展示课前发现的共性问题（核心事件定位不明 / 调用知识较为混乱）</p>

::: tip 课前要点
优秀的数据备课 = 明确筛选出得分率低的重点题，并用数据说明原因；
只「参考了数据但重点不够精准」只能达到达标线。
:::

## 三、课上讲解：大屏讲题 + 精准讲评 + 互动

<a id="in-class"></a>

### 核心原则：重点讲解共性题，不逐题讲解

只讲得分率低的题目，把课堂时间分配到真正卡住全班的地方；已掌握的题目一带而过或跳过，
避免冗余讲解挤占互动与巩固时间。

### 大屏讲题功能怎么用

- **展示作答详情**：查看学生选择选项情况、各选项分布，点名错选学生。
- **答案展示 / 主观题作答图片展示**：对学生作答进行点评，典型错解与优秀解法并排对比。
- **点名功能**：根据选项进行点名，抽查学生做题思路。
- **发送板书**：对重要题目做板书批注并一键发送给学生。

### 互动参与，让课堂「活」起来

- **随机点名 / 学生讲题 / 思路追问**：按选项点名追问，学生参与度高。
- **生生互评**：本课例中，全班唯一选 A 的同学被请上讲台讲解自己的思考过程，
  暴露问题后由同学互评纠正，效果远胜教师单向讲解。
- **小组讨论**：不同层次学生交流，小组解决不了的问题以小组为单位提出。

![学生举手互动](/images/student-interaction.jpg)

<p class="caption">课堂互动：学生举手 / 起立作答，课堂气氛活跃</p>

::: tip 大屏要点
大屏不是「投影仪」——要把选项分布、错选学生、板书批注发送等功能用足；
「用了大屏但功能利用不充分」只能算达标。
:::

## 四、当堂巩固：变式题即时反馈

<a id="consolidate"></a>

- 针对刚讲的共性薄弱点，**当堂发布变式题**（随堂练习）。
- 学生作答后系统完成**二次反馈**，正确率即时回显。

![课堂练习（变式题）](/images/inclass-practice.jpg)

<p class="caption">当堂发布课堂练习：大屏直接展示变式题，围绕核心事件 / 影响因素 / 效果逐项引导</p>

![学生当堂作答](/images/students-answering.jpg)

<p class="caption">学生全员作答：平板 / 学案同步进行，系统实时回收数据</p>

::: warning 巩固要点
讲—练—评必须在同一课时内闭环；布置了变式题却没当堂反馈，只能算达标，效果大打折扣。
:::

## 五、课后闭环：个性答疑 + 资源沉淀

<a id="after-class"></a>

- **板书发送学生**，配合语音讲题 / 录制微课解决个性问题（只针对非共性的「个别人」）。
- 学生端错题可看**视频解析**，完成自主纠错。
- 优秀课例**录制入库**，形成校本示范课资源，可复用、可推荐评比。
- 教师课后**分析数据**，调整教学策略，沉淀为下节课的学情起点。

## 六、完整教学操作流程（七步法）

以下七步法来自本页配套课例，可作为示范课标准动作清单：

1. 教师进入辅立码课后台，找到课程对应的考点及练习题，通过平台推送给学生；
2. 学生完成学案，通过 PAD 提交答案；错题看视频解析自主纠错；客观题系统自动批阅，主观题学生互阅；
3. 教师查阅任务得分率数据，实现精准备课；
4. 课堂上针对大家的共性问题进行重点解析；
5. 学生之间小组讨论，不同层次学生交流，小组解决不了的问题以小组为单位提出；
6. 教师针对小组问题答疑，对备课遗漏内容拓展补充；
7. 学生整理课堂笔记（板书已发送，可对照补充）。

## 七、组织一次公开示范课：5 天实施流程

| 阶段 | 关键动作 | 要点 |
| --- | --- | --- |
| 阶段一 · 选择教师 | 各学科组选教师示范，至少一文一理；内容为近期考试 / 作业讲评课；教务处排定时间 | 选「愿意用数据、表达力好」的教师更易出彩 |
| 阶段二 · 排课展示 | 校领导站台发言明确安排；安排 1–2 节课，学科教师全员听课；评委 = 校长 + 学科组长 + 运营代表（5–7 人）；统一评分表现场打分，课后评课 | 评委用统一评分表，避免主观 |
| 阶段三 · 点评入库 | 领导对使用与讲评环节简单点评；优秀课例录制入库，形成校本示范课资源 | 及时沉淀，避免「课上完就散」 |

## 八、示范课评分标准（自查 / 评委参考）

满分 100 分。开课前用它自查，开课后用它评课，清楚知道每一分从哪里来。

| 评价维度 | 评价要点 | 分值 | 优秀标准 | 达标标准 |
| --- | --- | --- | --- | --- |
| 课前数据备课 | 依托平台得分率数据确定讲评重点 | 15 | 明确筛出低分重点题，有数据支撑 | 参考了数据但重点不够精准 |
| 精准讲评 | 重点讲解共性题，不逐题讲解 | 25 | 只讲低分题，时间分配合理 | 有重点但仍有冗余讲解 |
| 大屏讲题应用 | 使用平台大屏讲题功能 | 20 | 展示选项分布、错选学生，板书批注并发送 | 用了大屏但功能不充分 |
| 互动参与 | 随机点名、学生讲题、思路追问 | 15 | 按选项点名追问，参与度高 | 有互动但形式单一 |
| 当堂巩固 | 发布变式题即时巩固 | 15 | 当堂发布变式题并完成二次反馈 | 布置了但未当堂反馈 |
| 课后闭环 | 板书推送、个性答疑 | 10 | 板书发送 + 语音讲题解决个性问题 | 有部分课后跟进 |

## 九、组织保障与激励

**工作小组**

- 校长牵头；教务处统筹排期与听评课组织；教师落实磨课；平台运营提供数据与培训支持。

**激励措施（有条件的可以组织）**

- 明星示范课教师全校表彰。
- 优秀课例收入校本资源库，优先推荐参加评比。

## 十、实操避坑指南

::: tip 1. 数据备课要「真用」
明确筛出得分率低的重点题并写清数据依据，否则评分只能到「达标」。
:::

::: tip 2. 精准讲评别「恋战」
只讲低分题，已掌握的题一带而过，把时间留给互动与巩固。
:::

::: tip 3. 大屏功能用足
展示选项分布 + 错选学生 + 板书批注发送，别只当投影仪用。
:::

::: tip 4. 互动要多样
按选项点名追问 + 学生讲题 + 生生互评，避免「一问一答」形式单一。
:::

::: warning 5. 变式题要当堂收反馈
布置了就当堂收二次反馈，别拖到下课铃响。
:::

::: tip 6. 课后闭环别漏
板书发送 + 语音 / 微课个性答疑，把「个别人」的问题也兜住。
:::
