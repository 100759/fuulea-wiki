# 如何上传试题

手里有一份现成的试卷（PDF 或 Word），想让它在平台上变成一道一道可布置、可批改的题，就走**上传试题**这条路。系统会用 AI 自动把整张卷子切成单题，并挂上答案和解析；切完检查一遍，就能直接发布成任务。

本篇配一段真实操作录屏（4 分 41 秒），从进入入口一直演示到发布设置。

## 1 操作流程

### 1.1 进入「上传试题」

登录教师端，左侧菜单点击【任务】，在任务列表右侧的**新建任务**面板里点【上传试题】。

![新建任务面板中的上传试题入口](/images/manual/img-upload-01.png)

### 1.2 添加试卷文件

会弹出【智能切题】窗口，第一屏是**上传文件设置**：

1. 点击虚线框【点击此处选择文档】
2. 选中试卷文件，也支持一次选多个

支持 **PDF、Word（doc / docx）** 格式。

![上传文件设置](/images/manual/img-upload-02.png)

选完文件后，表格里会列出每个文件，可以逐个设置属性。

### 1.3 标注属性、纸张与顺序

表格共五列：**文件名 / 属性 / 纸张 / 排序 / 删除**。

| 列 | 怎么填 |
| --- | --- |
| 属性 | 试卷正文选【试卷】；单独的答案文件选【答案解析】 |
| 纸张 | 按卷面实际大小选【普通】【中尺寸】【大尺寸】 |
| 排序 | 多个文件时用 ↑ ↓ 调整先后 |
| 删除 | 选错了点右侧 ⊗ 移除 |

::: warning 顺序不能错
如果**把试卷和答案解析一起上传**，务必按「**1. 试卷**在前、**2. 答案解析**在后」排列 —— 顺序反了，答案和解析会挂到错误的题目上。
:::

设置完成后点【开始切题】，等系统处理完（页数多的卷子要等一会儿）。

### 1.4 查看自动切题结果

切完进入复核界面。左边是原卷，每道题上套着一个识别框；右边是**试卷总览**：

- 选择题 12 题、主观题 2 道、共 14 道、共 80 分
- 下方逐题列出题型和分值，每题有【题干】【解析】两个页签

底部中间是页码（如 `1 / 10`），**一页一页翻过去核对**，别只看第一页。

![自动切题结果与试卷总览](/images/manual/img-upload-03.png)

### 1.5 修正切题框、题型与分值

AI 切题不会 100% 准，尤其是公式多、排版密的卷子。点中某一道题，题目上方会浮出工具条：

| 控件 | 作用 |
| --- | --- |
| 题号下拉 | 改题号 |
| 题型下拉 | 单选 / 多选 / 判断 / 填空 / 主观题等 |
| 分值 | 改本题分数 |
| 编辑 | 进入框选编辑，拖动边框重画 |
| 定位 | 跳到该题在原卷的位置 |
| 删除 | 不需要这道题就删掉 |
| 同变化 | 把同样的改动批量套用到其他题 |

底部还有几个常用开关：**自由模式**（手动画框，切漏了用它补）、**题目不完整**（标记被切成半截的题）、**分值**（快速批量设分）。

![选中单题后调整框选与分值](/images/manual/img-upload-04.png)

### 1.6 核对答案与解析

点底部【答案】切到答案视图。左边会按题显示【答案】【详解】【分析】；右边界面上每题点【解析】，可以单独看这一题的解析有没有对上。

解析缺失或串题，多半是 1.3 里属性或顺序没设对，回去重传一次答案文件即可。

![核对答案与解析](/images/manual/img-upload-05.png)

### 1.7 保存到课程库，或直接发布

右下角两个按钮，按需选：

- **保存到课程库** —— 只把切好的卷子存进题库，不发给学生；以后从「新建任务 → 我的试卷」再调用
- **发布任务** —— 直接往下走发布流程

## 2 发布设置怎么填

点【发布任务】后是三步流程：**① 发布设置 → ② 选择学生 → ③ 发布成功**。

第一步要填的内容：

| 项目 | 说明 |
| --- | --- |
| 任务名称 | 默认取试卷标题，可改 |
| 发布时间 | 【立即发布】，或设定时发布 |
| 截止时间 | 学生交作业的最后时限 |
| 基础设置 | 作业 / 教师批阅 / 允许换交 / 提交后可见，逐个点选 |
| 错题重练 | 个性错题 / 高频错题 / **不重练** |
| 提交方式 | 逐题拍照 / 分组拍照 / 纸质卡 |
| 补充信息 | 【+ 任务说明】，给学生写几句要求 |
| 更多设置 | 作答全部题目 / 不限时答卷 / 关闭学生讲题 |

![发布设置](/images/manual/img-upload-06.png)

::: tip 提交方式怎么选
选【分组拍照】时，下方会列出题组（如 13、14 两道主观题），同一组题目学生拍一张照片一起交。
:::

填完点【下一步】选学生，再确认发布。

## 3 常见问题

**切出来的题框不准、有漏题**

- 用底部【自由模式】手动画框补上
- 被切成半截的题，勾【题目不完整】，避免后面判分出问题
- 整页都没识别出来，先确认上传的是**文字版 PDF / Word**，纯扫描图片效果会差很多

**题型或分值不对**

- 选中该题，在浮动工具条里直接改
- 多道题改法一样，改好一道后点【同变化】批量套用

**答案和解析挂到了别的题上**

- 检查上传时是否把答案文件标注成【答案解析】、并且**排在试卷后面**
- 顺序错了需要重新上传

**能一次传几个文件**

- 可以多选。一张卷子拆成几个文件也可以，只要在 1.3 里把顺序排对
