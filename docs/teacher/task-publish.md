# 一、任务发布

## 任务发布介绍

老师日常发的作业在平台中统称为「**任务**」。点击左侧导航栏【任务】，选择需要下发的任务类型。辅立码课平台任务分为六种：**课程任务、资料任务、答题卡任务、题库选题任务、学科网选题任务、选卷任务**。

![任务入口](/images/manual/img-p04-02.png)

## 课程任务

辅立码课课程任务包括：「码上提分」精品课程、校本课程、名校课程。在【课程】界面可选择通过「码上提分」精品课程，或者在校本课程中选择需要发给学生的内容。

![课程任务界面](/images/manual/img-p04-04.png)

点击【布置任务】，可跳转到任务设置界面。

![任务设置界面](/images/manual/img-p05-02.png)

选择需要发布的任务，点击【布置任务】，会跳转到任务设置界面（详见下文[任务发布介绍](#任务发布介绍-1)）。

![布置任务](/images/manual/img-p05-04.png)

## 资料任务

点击【资料任务】之后，进入资料任务界面：输入任务名称，添加附件，编辑任务内容。可以把课堂使用的 PPT 或者英语听力发送给学生，支持多种文件格式。

::: warning 附件大小限制
资料任务附件大小限制 **80MB**。
:::

资料任务学生只可观看学习，不可以进行作答上传答案。

![资料任务](/images/manual/img-p06-02.png)

![资料任务编辑](/images/manual/img-p06-04.png)

## 答题卡任务

点击【制答题卡】任务，跳转到答题卡制作界面。

**第一步**：输入答题卡/试卷名称。

**第二步**：根据需要上传的题目进行答题卡部分的制作，根据实际选择题数量、非选择题数量添加题目的题号。选择题部分的答案，可以直接点击选择题答案。

**第三步**：上传需要文件的电子档，支持多种格式上传；附件部分可以上传英语的听力。Word 导入需要题目、答案分离，格式完整清晰的文件。

![答题卡制作界面](/images/manual/img-p07-02.png)

![答题卡制作](/images/manual/img-p07-04.png)

### 添加题目

点击【添加题目】，添加所需题型、题目数量、题号、选项个数、题目分值。

![添加题目](/images/manual/img-p08-01.png)

![题目设置](/images/manual/img-p08-02.png)

选择题勾选答案即可，多选题勾选多个答案。

![选择题答案](/images/manual/img-p08-04.png)

### 答案与解析

点击【答案/解析】设置答案/解析（可文字录入、复制粘贴、截图）。

![答案解析设置](/images/manual/img-p08-05.png)

### 切题

设置好答题卡的名称、选择题的答案，然后点击【切题】。

建议选择**逐题框选**、模式选择**快速**；在这个模式下可以给题目设置标准的边框线，只需要按住鼠标左键进行框选题目和答案。

![切题框选](/images/manual/img-p09-02.png)

![逐题框选](/images/manual/img-p09-04.png)

::: tip
可以将需要录入的资料发给工作人员辅助上传。
:::

## 背诵任务

::: warning 背诵任务只可上传音频

## 题库选题任务

通过【题库选题】可以跳转到题库界面，根据不同的筛选方式，选取自己需要的题目。

![题库选题](/images/manual/img-p11-02.png)

- **视频题目优先**：学生作答完成之后，到达答案公布时间的时候，题目会携带视频解析。
- **过滤已使用**：可以帮助老师筛选和排除已经使用过的题目。

![题库筛选](/images/manual/img-p11-04.jpg)

![题库列表](/images/manual/img-p12-02.png)

## 选卷任务

点击【选卷任务】会跳转到题库中的试卷选题部分，可以选择高考的真题部分，可以选取其中的试卷整套发布，同时学生也可以看到历年高考真题。

- 学校其他老师的试卷在【校本试卷】中可查看。
- 教师自己发布的任务试卷，可以在此界面中【我的试卷】中查看。

## 学科网选题

首次登录需要**微信扫码绑定学科网账号**，绑定后辅立码课账号即可与学科网账号进行关联，后续点击【学科网选题】即可自动登录。

学科网账号为老师的手机号/邮箱/用户名，或微信扫码登录。如果是学校新开的账号，系统会自动发送开通短信，短信内有初始密码。

![学科网绑定](/images/manual/img-p13-01.png)

点击学科网选题之后，会跳转到学科网的选题界面，在学科网中选择自己需要的题目，加入**选题篮**，然后点击【去组卷】，点击【选好了】，等待组卷完成之后进入辅立码课，可以以任务的形式发送给学生。

## 任务发布介绍

任务发布界面中：

**任务名称**：建议写任务发布时间+任务内容。

**时间设置**：

- 发布时间：根据需求填写，默认立即发布，可以设定发布时间
- 截止时间：默认自发布任务起 24 小时截止，可根据需求设定
- 公布答案：默认提交后可见。防止学生间传达答案，**建议设定答案公布时间**
- 允许晚交：默认允许。非必要时间限制的任务建议允许晚交，学生数据收集是常态化的动作，可以收集更完整的数据

**阅卷方式**：学生通过 Pad 提交作业，选择题系统会自动批阅，非选择题拍照上传，可以通过三种方式完成批阅：

| 阅卷方式 | 说明 |
| --- | --- |
| 学生互阅 | 用在非正式的批阅作业、练习等。优点是减轻老师阅卷负担：学生提交答案后，先根据答案自己改错，然后再批阅 1 至 2 份系统自动推送的其他同学试卷，也能通过评价别人来提升自己的理解水平 |
| 教师批阅 | 教师可通过微信小程序（辅立教学）或电脑登录网站批改作业，随时随地批改，解放固定时间、固定地点批改作业的障碍 |
| 学生自阅 | 学生自己批改作业 |

**错题重练**：打开之后，学生会在重练时间收到自己的原错题，**建议老师务必打开**。

**最大题量**：防止学生的错题太多，在错题重练时间收到自己原错题以及当日任务题目数量太多，建议设置任务的最大题量。

**重练时间**：默认错题重练时间是任务发布后隔一天，教师可自行设置。

**分组拍照功能**：方便教师进行批阅，学生拍照上传时可以两个题目拍在同一张图片中。例如想让学生 12-14 题拍在一张图片中，先点一下 12 题，再点击 14 题，可完成 12-14 题只拍一张照片。

条件设置好之后点击【下一步】，选择需要发送给的学生或者班级。如果是学科组长，可以点击【管理的班级】，找到需要发送给的班级，最后点击【发布任务】。

![任务发布界面](/images/manual/img-p16-01.png)

![选择发送对象](/images/manual/img-p16-02.png)

### 任务发布流程总结

```
设置任务名称 → 编辑任务时间（开始时间、结束时间、答案公布时间）
→ 阅卷方式选择 → 打开错题重练（设置最大题量）
→ 分组拍照设置 → 选择发送学生/班级 → 任务发布成功
```

## 码上提分精品课程介绍

码上提分精品课程包括：《高考考点全覆盖视频课程》《本科临界生》《一轮精品课》《高考真题》《新教材》《初高中衔接》《艺术生》《专题突破》。

![精品课程体系](/images/manual/img-p16-03.jpg)

### 高考考点全覆盖视频课程

覆盖高中 9 大学科所有考点，所有考点全部配有考点讲解视频，练习题全部配有视频解析。一轮复习过程中，可以通过辅立码课的「考点全覆盖」课程，将考点视频和基础练习题（3 道左右）推送给同学（学生自阅无需批阅，习题自带解析视频）。

### 本科临界生 — 黑马冲刺课

在高考考点全覆盖视频课程的基础上进一步筛选，帮助本科临界生快速定位需要关注的考点，节省时间提高效率。涵盖数学、化学、生物、历史、地理、政治学科。包含考点的知识梳理、知识点的视频课程精讲，以及考点下相对应的典型例题。

### 一轮精品课 — 分层精练精讲

满足不同学校的进度，提供符合一轮复习的精品课程，提供周测使用到的习题。包含两个模块：**夯实特控线、突破双一流**，满足班级内不同层次学生的需求。涵盖数学、物理、历史、政治学科。

### 高考真题课程

收录近 10 年的各省份高考试卷，并且全部习题进行了视频化，由名校老师精心录制了视频解析。

::: tip 使用建议
首先将本省的近 5 年高考真题制定计划，在二轮复习至高考前做至少一遍；其次再选择性地做其他省份的真题，熟悉高考出题的风格及思路。
:::

### 新教材同步课程

高中教材已全面更新，辅立码课邀请名校老师专门针对新教材同步编制了新教材的同步课程，每个章节全部配备考点视频讲解及配套练习题。高一、高二老师在讲授新课过程中，可以同步使用。

### 初高中衔接课

初中课程和高中课程之间的跨度过大，无论是在题目的数量还是在课程的难度上。为帮助学生快速适应高中的节奏，提供初高中衔接课程，可以帮助学生提前预习高中的课程，辅助学生快速适应高中生活。

### 艺术生百日冲刺课程

为艺体生在高考前的 3 个月系统进行复习、快速提升成绩而设计，内容更加精简，选取了高考经常考察的考点汇总整理而成。经实际验证，此课程同样适用 200-400 分的同学学习。

::: tip 使用建议
如果成绩处在中下游，对许多考点掌握程度还不够好，可以在考前 3 个月内，认真学习此课程内容。
:::

### 专题突破

涵盖高中九大学科，帮助学生实现专题突破，找到相对应薄弱的专题，学习模块中梳理本专题的知识点，配备视频讲解。例题选取中照顾不同层次的学生：**基础必会题**（保住 500 分）、**综合提升题**（冲刺 600 分）、**过关检测**（飞跃本一线）。
