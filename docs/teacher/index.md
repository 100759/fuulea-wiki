# 教师端操作手册

本手册面向使用辅立码课的老师，完整覆盖日常教学动作。内容整理自《辅立码课教师操作手册》（2025 年 6 月版）。

## 手册结构

### [任务发布](/teacher/task-publish)

老师日常发的作业在平台中统称为「任务」。本章介绍六种任务类型的制作与发布流程：

- 课程任务 / 资料任务 / 答题卡任务 / 背诵任务
- 题库选题任务 / 选卷任务 / 学科网选题
- 选题篮、任务发布设置（时间、阅卷方式、错题重练）
- 码上提分精品课程体系介绍

### [教学场景应用](/teacher/teaching-scenes)

任务发布成功后，如何用数据反哺课堂教学：

- 大屏讲题（板书讲解、随机点名）
- 批改阅卷（按题阅/按人阅、打分、分享、打回、文字标注）
- 完成统计（任课教师视角 + 班主任视角）
- 错题反扫（重练统计、共性错题、错题重练修改）

### [细化使用](/teacher/advanced)

高阶功能与专项模块：

- 举一反三 / 催交作业
- 靶向教学（对人靶向、对点靶向、靶向班创建）
- 信息修改（任务详情、删除学生、修改密码）
- 考试系统（创建考试、答题卡制作、扫卡阅卷）
- 学情诊断（年级/班级/个人画像）
- 创建课程、知识点关联
