# 细化使用

## 3.1 举一反三

在已发布过的任务中，除了可以看到学生作答详情，还可以帮助学生进行错题巩固。

点击【举一反三】之后，可以：

1. 给学生发送原错题
2. 提供相似知识点的题目，供教师选择
3. 根据实际情况选择需要发送到的学生，在相对应的方框勾选即可
   - 可以发送正确的人、错误的学生
   - 点击【更多】可以根据学生作答的选项发送给学生
4. 设置完成之后点击【已选】

![举一反三](/images/manual/img-p27-01.png)

![选择发送对象](/images/manual/img-p27-02.png)

检查选中的题目部分是否满足需求，可以删减题量，更改需要发给的学生；右侧可以看到题目会发送给的学生。

![确认题目](/images/manual/img-p28-01.png)

## 3.3 靶向教学

把鼠标慢慢移动到靶向的位置，会出现【对人靶向】【对点靶向】。

### 3.3.1 对人靶向

**第一步**：找到任教/学生所在的班级。

**第二步**：设置好科目（可以是全科/任教的学科），设置某段时间的学情（开始时间、结束时间）。

**第三步**：找到学生的姓名，也可以通过搜索去寻找需要靶向提升的学生，然后点击学生姓名。

在此界面可以看到学生某段时间内，总分的平均分、平均排名、最近排名等信息。

![对人靶向](/images/manual/img-p30-01.jpg)

![学生学情总览](/images/manual/img-p30-02.png)

可以看到学生的每个学科的成绩排名，**标红的部分表示是拉分的学科**，可以针对这些学科进行靶向提升。点击薄弱学科的学情图谱。

![学科成绩排名](/images/manual/img-p31-01.jpg)

![学情图谱](/images/manual/img-p31-02.png)

点击具体知识点（如「函数及其表示」）→ 点击【对题靶向】。

![对题靶向](/images/manual/img-p32-01.png)

可从**全部错题 / 高考真题 / 相似题**中选择题目推送给学生，达到「对人、对点、对题」个体培优的效果。

![选择题目](/images/manual/img-p32-02.png)

### 3.3.2 对点靶向

针对于此知识点下，学生的得分情况会被展示在学生学情中：

1. 可以根据学生的得分率**框选柱状图**，框选完成后右侧部分学生姓名之前会出现对勾
2. 也可以通过**双维度分布**框选学生
3. 需要调整部分，直接取消学生前边的对勾即可
4. 对这些学生创建**靶向班**进行题目的推送

![对点靶向](/images/manual/img-p33-01.jpg)

![框选学生](/images/manual/img-p33-02.png)

提供多种选题方式：**共性错题、高考真题、题库选题**，方便找到题目进行题目的推送。

::: tip 选题建议
建议在题目选取的时候选择具备**视频解析**的题目，方便学生完成题目后及时进行习题的巩固。
:::

题目选取之后加入选题，可以发送到创建的靶向班。

![选题推送](/images/manual/img-p34-01.png)

### 3.3.3 靶向班创建

**方式一：手动创建**

点击左侧【系统管理】【我的班级】，点击右上角【创建班级】，选择年级，填写班级名称，类型选择【靶向班】，点击【确定】，创建成功。

![手动创建靶向班](/images/manual/img-p34-02.png)

![靶向班设置](/images/manual/img-p34-03.png)

![选题方式](/images/manual/img-p34-04.png)

**方式二：根据知识点创建**

1. 点击左侧导航栏【任务】，找到发布的任务
2. 点击打开任务，点击【完成情况】
3. 点击得分率柱状图，或者题号，点击右侧【+靶向班】创建靶向班
4. 所有做错本题的同学都会加入到靶向班，根据需求勾选【发布任务后解散】【加入学生任课老师】，点击【确定】，靶向班创建成功

![任务完成情况](/images/manual/img-p35-01.png)

![得分率柱状图](/images/manual/img-p35-02.png)

![根据知识点创建](/images/manual/img-p35-03.jpg)

**方式三：根据选项创建**

点击题目某选项（如第八题 B 选项）柱状图，可以筛选出本题所有选择 B 选项的同学，点击【+靶向班】创建靶向班。

![根据选项创建](/images/manual/img-p35-04.jpg)

**方式四：根据得分率创建**

点击【成绩详情】，筛选得分率，勾选学生名字，可以创建靶向班。

![根据得分率创建](/images/manual/img-p36-01.png)

**方式五：根据分值创建**

点击【对比分析】，点击【成绩表】，筛选【得分】或者【得分率】，勾选学生姓名，点击【+创建靶向班】创建靶向班。

![根据分值创建](/images/manual/img-p36-02.png)

## 3.5 考试系统

### 3.5.1 考试创建与答题卡设置

**1. 创建考试**

点击左侧导航栏【考试】按钮进入考试页面，点击右上角【创建考试】，根据提示填写必填项目。

::: warning 交卷方式
需要使用扫描仪扫卡阅卷，交卷方式可选择【扫卡】；也可以选择【Pad 提交】。
:::

![创建考试](/images/manual/img-p40-01.png)

**2. 新建答题卡**

初次创建答题卡需要在考试页面右上角创建【纸质答题卡】，进入之后继续点击【新建答题卡】。

::: tip 模板复用
第一次答题卡模板创建之后自动保存，后续考试可在原版本微调后下载上传即可。
:::

![新建答题卡](/images/manual/img-p40-02.png)

![考试学科设置](/images/manual/img-p40-03.jpg)

**3. 答题卡创建注意事项**

- 不同答题卡布局下方有不同适用纸张提示，请仔细核对后再添加题目
- 添加题目可批量添加，建议根据题号按类型创建（如每次考试答题卡区域不变，请核对分数是否有调整，调整往期答题卡点击题目即可修改分值）
- 答题卡创建之后可在右下角点击【预览】，预览答题卡样式再进行微调确认
- 如需**试题分小题阅卷**，可在题目右上角点击【添加小题】按钮
- 如需添加填空题答题区域，需在空白区域内设置下划线并按空格调整长度（如填空题分数整体给分，需设置成解答题）

![答题卡布局](/images/manual/img-p41-02.png)

**4. 保存并下载模板**

答题卡创建并预览没有问题之后，请点击右下角【保存】按钮，下载模板。

::: danger 打印注意
下载的模板请注意文档尺寸，在打印时**严格匹配对应纸张的尺寸**，打印过程中**禁止缩放**。
:::

![保存下载](/images/manual/img-p42-01.png)

### 3.5.2 答题卡上传及后续操作

1. 点击考试进入考试学科设置页面，在学科下有【设置模板】按钮，点击即可将创建好的答题卡模板上传（上传成功之后在学科下便有考试内容编号）
2. 上传成功之后点击【答案设置】，根据考试答案逐题设置即可
3. 设置好之后即可等待考试结束后通过码课考试扫卡系统扫卡（Pad 提交考试没有此步骤）

![设置模板](/images/manual/img-p43-01.jpg)

### 3.5.3 答题卡扫描（仅扫卡模式需要）

1. 整理好答题卡，打开「辅立码课扫卡客户端」（需要提前安装），再通过 USB 数据线连接扫描仪

   ::: warning 注意先后顺序
   :::

2. 点击进入考试，在需要扫卡的学科后点击【扫描答题卡】，选择考试班级并确认
3. 开始扫卡，放入一张答题卡。第一张扫描后会出现**校验页面**，校验红框是否将答题框全部覆盖
4. 扫卡过程中会出现**异常试卷**，点击【异常情况】即可进入异常试卷处理页面（请不要重复提交）

**常见异常卷处理方式**：

| 异常类型 | 处理方式 |
| --- | --- |
| 考号识别异常 | 根据学生卷面信息输入考号或姓名检索提交即可 |
| 客观题异常 | 根据学生涂卡情况及提示缺失题目勾选即可；如果学生没有填直接提交 |

5. 扫卡结束并解决异常卷之后，返回考试页面，开始【阅卷分配】，为老师分配批阅题目
6. 返回考试页面点击【开始阅卷】即可阅卷
7. 阅卷结束后，点击【结束阅卷】
8. 结束阅卷后，可进行成绩统计查询及 Excel 导出

![扫卡校验](/images/manual/img-p43-02.jpg)

![异常试卷处理](/images/manual/img-p43-03.jpg)

## 3.7 创建课程

### 3.7.1 课程创建界面

1. 在首页点击【课程】
2. 点击【创建课程】

课程创建界面填写步骤：

1. 填写课程的名称
2. 修改课程的**可见性**：
   - 仅自己可见
   - 学校老师（学校内老师都可以看见）
   - 全体学校用户（学校老师、学生都可以看见）
3. 勾选使用年级和级部
4. 添加标签（如自学课程、复习资料等等）
5. 课程简介（可写课程概要）
6. 如果有课程封面可上传
7. 最后点击【下一步】

![创建课程](/images/manual/img-p46-03.png)

![课程信息填写](/images/manual/img-p47-01.png)

### 3.7.2 章节目录编辑

目录设置中**最多可设置三级目录**：

- 一级目录添加需要点击【添加章节】
- 二级标题添加需要在一级章节目录下，点击右侧的加号
- 三级标题添加需要在二级目录下，点击右侧加号
- 可以删除章节内容

章节设定完成之后点击【下一步】。

![章节目录](/images/manual/img-p47-02.png)

**章节内容编辑**，可在章节中添加：

| 模块 | 说明 |
| --- | --- |
| 知识模块 | 学生需要学习的内容 |
| 练习模块 | 添加习题，方便学生巩固 |
| 制答题卡 | 上传题目，可参考制答题卡任务 |

最后点击【完成】。

![章节内容编辑](/images/manual/img-p48-01.png)

![完成创建](/images/manual/img-p48-02.png)

## 3.8 知识点关联

### 3.8.1 校本课程关联知识点

1. 点击左侧导航栏【课程】，点击校本课程需要关联知识点的目录课程
2. 点击需要关联知识点的章节目录
3. 点击右上角【关联知识点】
4. 可从【知识点】【思想方法】【能力】三种逻辑里边勾选正确的知识点及其他
5. 点击【下一题】，即可完成本题的知识点关联

![关联知识点](/images/manual/img-p49-01.png)

![勾选知识点](/images/manual/img-p49-02.png)

### 3.8.2 任务题目关联知识点

点击左侧导航栏【任务】，点击需要关联的任务，点击【任务详情】，点击【题目关联图谱】或者【+关联】关联知识图谱，即可完成。
