# 如何导入成绩

考试结束、阅卷系统出完成绩后，需要把成绩导入平台，才能在**完成统计、错题反扫、学情诊断**里看到数据。本篇用一段真实操作录屏（2 分 38 秒）演示完整流程，并附关键截图。

## 1 操作流程

### 1.1 打开考试任务详情

登录教师端，左侧菜单点击【任务】，在列表里找到这次考试对应的任务，点击进入**任务详情**页。

![任务列表](/images/manual/img-import-06.png)

### 1.2 点击「导入成绩」

在任务详情页右上角，【编辑】按钮旁边就是【导入成绩】，点击进入导入页面。

![任务详情页的导入成绩入口](/images/manual/img-import-01.png)

### 1.3 选择数据源

导入页面第一项是**数据源**，统一选择**全通教育**：


不管学校用的是哪一家阅卷系统，统一选全通教育。

![导入成绩页面](/images/manual/img-import-04.png?v=2)

### 1.4 下载班级对照表

点击【班级对照表】右侧的【下载】，会拿到一个 Excel 文件，文件名类似
`三校协作2026-2027学年第一学期联考班级对照表.xlsx`。

- **小题分**：按学生列出各小题得分，是成绩数据的模板


### 1.5 填充模版并上传

我们把学生的小题分“严丝合缝”的复制到模版上。

![班级对照表模板](/images/manual/img-import-02.png)

::: warning 多班级同时上传
一次上传多个班级的成绩时，直接将多个班级学生成绩和小题分复制到一张表即可。
:::

准备好后保存一下。随后点击【上传文件】

### 1.6 点击「导入」

确认数据源、班级对照表、附件都就绪后，点击页面右下角的【导入】。

## 2 导入结果在哪看

导入是否成功，看右上角的消息通知：

点击页面右上角的**铃铛图标** → 【系统消息】，能看到一条
`【云平台通知】导入任务数据` 的通知，里面写明：

- **成功**：导入的文件名、导入学生数（如「导入学生: 31」）
- **失败**：失败原因

![系统消息中的导入结果](/images/manual/img-import-05.png)

导入成功后，回到任务详情页，【完成统计】【错题反扫】等页面就有数据了。

## 3 常见问题

**导入失败**
- 确认模版是否是严丝合缝
- 试卷小题分分值大于上传小题分分值。
- 上传小题分分值大于题目满分
