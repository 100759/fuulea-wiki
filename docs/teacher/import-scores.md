# 如何导入成绩

考试结束、阅卷系统出完成绩后，需要把成绩导入平台，才能在**完成统计、错题反扫、学情诊断**里看到数据。本篇用一段真实操作录屏（2 分 38 秒）演示完整流程，并附关键截图。

## 1 操作流程

### 1.1 打开考试任务详情

登录教师端，左侧菜单点击【任务】，在列表里找到这次考试对应的任务，点击进入**任务详情**页。

![任务列表](/images/manual/img-import-06.png)

### 1.2 点击「导入成绩」

在任务详情页右上角，【编辑】按钮旁边就是【导入成绩】，点击进入导入页面。

![任务详情页的导入成绩入口](/images/manual/img-import-01.png)

### 1.3 选择数据源

导入页面第一项是**数据源**，按你学校使用的阅卷系统选：

| 数据源 | 适用 |
| --- | --- |
| 智学网 | 智学网阅卷系统 |
| 全通教育 | 全通教育阅卷系统 |
| 达美嘉 | 达美嘉阅卷系统 |
| 好分数 | 好分数阅卷系统（仅总分） |
| 好分数-小分表 | 好分数阅卷系统（含小题分） |

**选错数据源会导不进数据**，选之前先确认学校用的是哪一家。

![导入成绩页面](/images/manual/img-import-04.png)

### 1.4 下载班级对照表

点击【班级对照表】右侧的【下载】，会拿到一个 Excel 文件，文件名类似
`三校协作2026-2027学年第一学期联考班级对照表.xlsx`。

这个表里有两个工作表：

- **小题分**：按学生列出各小题得分，是成绩数据的模板
- **班级对照表**：班级名称的映射关系，**文件名里必须包含完整的班级名称**，否则平台认不出是哪个班

![班级对照表模板](/images/manual/img-import-02.png)

### 1.5 上传阅卷系统导出的文件

点击【上传文件】，选择阅卷系统导出的答题详情。

::: warning 多班级同时上传
一次上传多个班级的成绩时，必须保证每个文件名中都包含**完整的班级名称**（如「…高三9班…」），
平台是按文件名里的班级名去匹配学生的，名字不完整会导致该班学生匹配不上。
:::

![小题分数据](/images/manual/img-import-03.png)

### 1.6 点击「导入」

确认数据源、班级对照表、附件都就绪后，点击页面右下角的【导入】。

## 2 导入结果在哪看

导入是否成功，看右上角的消息通知：

点击页面右上角的**铃铛图标** → 【系统消息】，能看到一条
`【云平台通知】导入任务数据` 的通知，里面写明：

- **成功**：导入的文件名、导入学生数（如「导入学生: 31」）
- **失败**：失败原因

![系统消息中的导入结果](/images/manual/img-import-05.png)

导入成功后，回到任务详情页，【完成统计】【错题反扫】等页面就有数据了。

## 3 常见问题

**导入失败/导入学生数为 0**

- 数据源选错了，换成学校实际使用的阅卷系统再试
- 文件名里没有完整班级名称，导致学生匹配不上
- 班级对照表版本过期，重新下载最新的再用

**导入后看不到某个班的数据**

该班学生没有匹配上。检查上传文件的班级名称是否和班级对照表一致，必要时在「学生姓名前缀」里补上统一的前缀。

**支持哪些格式**

上传阅卷系统导出的答题详情（Excel），同时可上传多个班级的文件。
